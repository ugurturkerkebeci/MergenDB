# Mergen Studio

[![Socket Badge](https://badge.socket.dev/npm/package/mergendb/0.8.4)](https://badge.socket.dev/npm/package/mergendb/0.8.4)

Official Web Management Dashboard extension for **MergenDB**.

## Installation

```bash
pip install mergendb-studio
```
or via MergenDB optional extra:
```bash
pip install "mergendb[studio]"
```
or via the Mergen CLI:
```bash
mergen studio install
```

## Usage

Start the MergenDB server:
```bash
mergen serve
```
Open your browser and navigate to:
```
http://localhost:8765/studio
```
